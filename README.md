# smangos

A vmangos-based server for the 1.15 Classic Era client.

## Getting Started

Documentation is published at <https://smangos-project.github.io/smangos/>; the sources live in [docs-site](docs-site).

- [setup](docs-site/docs/setup.md): How to build and set up smangos.
- [differences](docs-site/docs/differences.md): How smangos differs from vmangos and other emulators

## Working on the docs

```
cd docs-site
npm ci
npm start
```
